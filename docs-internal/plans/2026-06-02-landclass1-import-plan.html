🗺️ 개요

봉화군 및 전국 기관용 토양 시료 접수 대장에 두 가지 기능을 추가합니다.

  • 경지구분 1차 필드 추가 + 경지구분별 독립 번호/탭
  • 흙토람式 가져오기 모달 (엑셀 업로드/붙여넣기 → 컬럼 매핑 → 일괄 등록)
농촌진흥청 토양검정업무시스템이 경지구분(개량제·직불·자체 등)별로 따로 등록·번호를 매기는 방식을 그대로 반영합니다. 기존 데이터 모델은 건드리지 않고 landClass1 필드를 순수 추가하는 비파괴 설계입니다.

🏷️ 기능 1 · 경지구분 1차 필드

📍 폼 위치 & 신규 드롭다운

토양 접수 폼의 토양 시료 정보 영역에서 구분 · 목적(용도) · 경지구분 1차 세 항목을 한 줄(3열)에 나란히 배치하고, 비고는 그 아래 전체 너비로 둡니다. (현재 폼: src/soil/index.html 240~268줄에 #subCategory·#purpose·#note 존재 — 기존 2열 배치를 3열로 확장)

🗃️ 데이터 모델

  • 레코드에 landClass1 필드 신규 추가 (순수 추가)
  • 기존 subCategory(구분) / purpose(목적) / note(비고) 는 그대로 유지

🔗 흙토람 연동

현재 src/heuktoram/heuktoram-script.js 내보내기에서 경지구분 1차에 해당하는 dataRow[4] 가 '농가의뢰' 로 하드코딩되어 있습니다 (확인: 1541줄).

개선: dataRow[4] 를 레코드의 landClass1 값으로 연동하고, 비어 있으면 기본값 농가의뢰 를 사용합니다.

🔢 기능 1b · 경지구분별 독립 일련번호 + 목록 탭

🔢 독립 시퀀스

접수번호 시퀀스를 (연도 + 경지구분 1차) 단위로 독립 관리합니다. → 개량제 1·2·3…, 직불 1·2·3… 각각 1부터 시작.

  • 레코드 고유키 = 연도 + landClass1 + receptionNumber
  • 중복 검사 · 다음번호 자동추천도 이 단위로 동작

🗂️ 목록 탭

  • 접수 목록 화면 상단에 경지구분 1차 탭(또는 드롭다운) 배치
  • 선택 분류의 레코드만 자체 번호로 표시, "전체" 보기 옵션 유지
  • 통계 · 엑셀 내보내기는 현재 선택 탭 기준
저장 구조 참고: soilSampleLogs_{year} (연도별 배열, 각 레코드 receptionNumber 보유).

📦 기능 1c · 기존 데이터 마이그레이션

  • landClass1 없는 기존 레코드 → 기본 농가의뢰 탭에 귀속
  • 표시 시점에 기본값 부여 (lazy default)
기본값 농가의뢰 는 현재 흙토람 하드코딩값과 동일하므로, 기존 내보내기 결과와 100% 일치 — 안전한 마이그레이션입니다.

📥 기능 2 · 가져오기 모달 (흙토람式)

기존 src/soil 의 단순 엑셀 읽기 가져오기를 흙토람式 모달로 교체합니다. 참고 패턴: src/heuktoram/heuktoram-result-importer.js + 흙토람 모달 구조.
