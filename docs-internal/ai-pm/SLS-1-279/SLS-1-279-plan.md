# SLS-1-279 플랜 — 주소 열이 남는 폭을 흡수 · 관리 열 구분선

> 정본. `docs/01-plan/`의 사본은 훅 통과용 일회용이다.

작성: 2026-08-27 · 근거: `SLS-1-279-direction.md`

## 1. 남는 폭을 한 열이 흡수한다

`.data-table`이 `width: 100%`라 표가 화면보다 좁으면 남는 폭이 **모든 열에** 분배된다.
한 열에 `width: 100%`를 주면 그 열이 남는 폭을 가져가고 나머지는 내용 폭에 머문다.

### `src/soil/index.html`

```html
<th class="col-lot-address">필지 주소</th>
```

`td`에는 이미 이 클래스가 있다(`soil-script.js:4041`). 머리글에만 없었다.

### 퇴비는 흡수 열을 두지 않는다 — codex 리뷰로 뒤집힌 결정

초안은 퇴비의 농장주소(`col-farm-address`)를 흡수 열로 삼으려 했다. **세 가지가 막는다.**

1. **그 열은 250px 고정이 의도적 설계다.** `width`·`min-width`·`max-width`가 모두
   250px이고 `white-space: normal`로 **두 줄 표시**한다(`compost-style.css:759`).
   `max-width` 때문에 `width: 100%`를 줘도 흡수가 **아예 되지 않는다**(codex 지적).
   억지로 풀면 그 설계를 깨뜨린다. 주소(`col-address`)도 똑같이 250px 고정이다.
2. **발현 조건이 훨씬 넓다.** 퇴비 표는 원래 넓어(2066px) 실측상 **2150px 이상**에서만
   남는 폭이 생긴다. 토양은 1700px부터다.

   | 화면 폭 | 퇴비: 표가 넘치나 | 폭이 바뀐 열 |
   | --- | --- | --- |
   | 1800 | 넘침 → 넘침 | **0개** |
   | 2200 | 딱 맞음 → 넘침 | 16개 |
3. **남은 후보가 마땅치 않다.** 주소 계열을 빼면 면적·축종·생산일처럼 짧은 열뿐이라,
   어느 것에 몰아도 부자연스럽다.

→ 퇴비는 **구분선 색만** 고친다. 흡수 열은 백로그로 남긴다.

### `src/style.css` (공용)

```css
/* 남는 폭은 이 열 하나가 흡수한다 (SLS-1-279).
   ⚠️ 공용 규칙이다 — 다른 페이지가 이 클래스를 쓰면 그쪽에도 걸린다. */
.data-table .col-lot-address {
    width: 100%;
}
```

> ⚠️ **`width: 100%`는 "이 열을 화면 폭만큼"이 아니다.** 표 레이아웃에서는
> "남는 폭을 이 열에 몰아라"로 동작한다. 다른 열이 내용 폭을 먼저 가져간 뒤
> 남은 것을 이 열이 받는다. `white-space: nowrap`이라 내용보다 좁아지지도 않는다.

**실측(1800px, 전체 보기 토글)**: 폭이 바뀌는 열이 **14개 → 1개**(필지 주소 336→208).

## 2. 관리 열 왼쪽 구분선을 다른 열과 맞춘다

관리 열은 오른쪽 고정이라 스크롤되는 내용 **위에 떠 있다.** 그 경계는 다른 경계보다
분명해야 하는데 지금은 가장 약하다.

| 파일 | 지금 | 바꿀 값 |
| --- | --- | --- |
| `soil-style.css:988` | `#e2d9c8` (연한 베이지) | `#d0d7de` |
| `soil-style.css:1069` (다크) | `#44403c` | `#57534E` |
| `compost-style.css:1798` | `#bbf7d0` (연한 초록) | `#d0d7de` |
| `compost-style.css:1834` (다크) | `#14532d` (짙은 초록) | `#57534E` |

`2px`와 `solid`는 그대로 둔다 — 고정 열임을 나타내는 표시다.
1024px 이하의 `border-left: none`(SLS-1-260)도 그대로 둔다.

## 하지 않는 것

| 항목 | 이유 |
| --- | --- |
| 퇴비의 흡수 열 | 위 절 참조 — 주소 열 250px 고정이 의도적 설계이고 발현 조건이 2150px 이상이다 |
| `table-layout: fixed` | 22열 전부에 폭을 명시해야 한다. 흡수 열 하나로 같은 결과를 얻는다 |
| 표를 `width: max-content`로 | 사용자가 세 안 중 이것을 고르지 않았다 |
| 열 구분선 전체 재정비 | 요청 범위 밖 |

## 검증

| 종류 | 내용 |
| --- | --- |
| E2E | 1800px에서 전체 보기 토글 → **흡수 열 외에는 폭이 안 바뀐다** (토양) |
| E2E | 좁은 화면(1440px)에서는 원래대로 아무 열도 안 바뀐다 — 회귀 방지 |
| E2E | 흡수 열이 내용보다 좁아지지 않는다 (`nowrap` 최소 폭 보장) |
| E2E | **공익직불제 탭 + 전체 보기**를 함께 켜도 흡수 열 외에는 안 바뀐다 (codex 제안) |
| E2E | 전체 보기 토글 시 `table-scroll-anchor` 보정이 흡수 열과 함께 여전히 동작한다 (codex 제안) |
| E2E | 관리 열 왼쪽 경계 색 == 일반 열 경계 색 — **라이트·다크 각각** (토양·퇴비) |
| E2E | 좁은 화면에서 관리 열 고정이 풀리고 경계선이 없다 — 토양 1024px, 퇴비 1200px (SLS-1-260 회귀) |
| 실기 | Electron에서 눈으로 |

**변이 검증**: `width: 100%`를 지우면 "흡수 열 외에는 안 바뀐다"가 실패해야 한다.
구분선 색을 되돌리면 색 비교가 실패해야 한다.
