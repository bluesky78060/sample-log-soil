# SLS-1-280 플랜 — 구분선·채움 행이 끝 열에 닿게

> 정본. `docs/01-plan/`의 사본은 훅 통과용 일회용이다.

작성: 2026-08-27 · **SLS-1-276이 만든 회귀**

## 무엇이 잘못됐나

SLS-1-276에서 농가 구분선의 하드코딩 `colSpan`(모드별 18/19)을 없애고
`_visibleColumnCount()`로 **지금 보이는 열만 정확히 세도록** 바꿨다.
codex 플랜 리뷰가 "구분선과 채움 행이 같은 계산을 써야 한다"고 지적한 것을 받은 것이다.

**그 "정확함"이 결함을 만들었다.**

전체 보기 토글은 **목록을 다시 그리지 않는다** — 표의 class만 바꾼다
(`soil-script.js:_bindViewToggle`, 주석에 그렇게 적혀 있다). 그래서 기본 보기에서
만들어진 행들은 **그때의 열 수를 그대로 갖고 있다.**

실측(1500px, 12건):

| | 보이는 열 | 구분선 `colSpan` | 결과 |
| --- | --- | --- | --- |
| 기본 보기 | 17 | 17 | 맞다 |
| **전체 보기** | **19** | **17 (그대로)** | **마지막 두 열에 닿지 않는다** |

전체 보기의 열 순서로 세면 17번째가 `비고`다. 그 뒤 `발송일자`·`관리`에 초록
구분선이 미치지 않는다 — 사용자가 실기에서 본 그대로다.

> 💡 **역설적으로 옛 하드코딩은 이 문제가 없었다.** 기본 보기(17열)에 19를 주면
> 초과라 브라우저가 잘라 주고, 전체 보기(19열)에는 딱 맞았다. 값 하나로 두 모드를
> 덮고 있었던 것이다.

## 처방 — `colSpan`은 넉넉해야 한다

**초과하면 브라우저가 실제 열 수로 잘라 준다. 모자라면 이렇게 눈에 띈다.**
비대칭이므로 넉넉한 쪽으로 잡는다.

머리글 전체 칸 수를 쓴다 — 숨긴 열까지 포함해 **22**다. 어떤 모드에서도 모자라지 않는다.

### `src/soil/soil-script.js`

```js
_columnSpan() {
    const head = this.logTable?.tHead?.rows[0];
    return head ? head.cells.length : SOIL_TOTAL_COLUMN_COUNT;
}
```

`_visibleColumnCount()`를 대체한다. 구분선과 채움 행이 여전히 **같은 하나**를 쓰므로
SLS-1-276에서 codex가 지적한 "계산이 갈라진다"는 문제는 그대로 해결된 상태다.

상수 `SOIL_DEFAULT_COLUMN_COUNT = 19`(보이는 열 수)를 `SOIL_TOTAL_COLUMN_COUNT = 22`
(머리글 전체)로 바꾼다.

### `src/shared/pagination.js` (퇴비)

`getColumnCount()`가 같은 방식이다. 퇴비에는 구분선이 없고 채움 행만 있지만, 전체
보기에서 채움 행이 짧아지는 것은 같다.

```js
getColumnCount() {
    const head = this.elements.tableBody?.closest('table')?.tHead?.rows[0];
    return head ? head.cells.length : 1;
}
```

## 왜 "다시 그리게" 하지 않나

토글 때 `renderCurrentPage()`를 부르면 값이 맞겠지만, 수천 행을 다시 그린다.
`colSpan`을 넉넉히 주는 것으로 끝나는 일에 그 비용을 치를 이유가 없다.

## 검증

| 종류 | 내용 |
| --- | --- |
| 유닛 | `_columnSpan()`이 숨긴 열까지 센다 |
| 유닛 | 구분선과 채움 행이 여전히 같은 값을 쓴다 |
| E2E | **전체 보기에서 구분선이 마지막 열까지 닿는다** (지금 실패하는 시나리오) |
| E2E | 채움 행도 마지막 열까지 닿는다 |
| E2E | 기본 보기에서도 닿는다 (초과가 무해함을 확인) |
| E2E | 공익직불제 탭에서도 닿는다 |
| 실기 | Electron에서 눈으로 |

**변이 검증**: `head.cells.length`를 "보이는 열만"으로 되돌리면 전체 보기 E2E가
실패해야 한다.
