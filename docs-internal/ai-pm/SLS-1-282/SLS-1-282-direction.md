# SLS-1-282 Discovery — 퇴비 목록의 열 폭

> 정본. 훅 통과용 사본은 `docs/00-discovery/`.

작성: 2026-08-27 · 상태: **방향 확정** (사용자 선택)

## 어디서 나왔나

SLS-1-279에서 **의도적으로 백로그로 남긴 것**이다. 토양은 그때 고쳤고 퇴비는 뺐다.
v1.14.15 배포 뒤 사용자가 "퇴비 목록 열 폭도 고쳐줘"라고 지시했다.

## 왜 그때 뺐나 — 그리고 왜 지금은 되나

`col-farm-address`는 `width`·`min-width`·`max-width`가 모두 250px이고
`white-space: normal`로 **두 줄 표시**한다(`compost-style.css:759`).
`max-width` 때문에 `width: 100%`를 줘도 **흡수가 아예 일어나지 않는다** —
당시 codex 플랜 리뷰가 이것을 MAJOR로 잡았다.

**`max-width`만 풀면 동작한다.** `min-width: 250px`가 남으므로 표가 화면보다 넓을
때는 예전과 똑같다 — "표를 밀지 않는다"는 원래 의도가 그대로 지켜진다.
남는 폭이 있을 때만 그 열이 받는다.

## 실측 (2200px, 전체 보기 토글 전후)

| 안 | 폭이 바뀐 열 | 평소 화면 |
| --- | --- | --- |
| 지금 | **16개** (최대 −21px) | 농장주소 250px — 긴 주소가 두 줄로 접힌다 |
| **농장주소 흡수** | **1개** | 농장주소 303px — **한 줄로 들어간다** |
| 비고 흡수 | 1개 | 비고 74 → 126px, 주소는 계속 두 줄 |
| 주소 흡수 | 1개 | 주소 303px |

셋 다 효과는 같다(16 → 1). 차이는 평소 화면뿐이라 **사용자가 그림을 보고 골랐다** —
농장주소.

## 발현 조건

퇴비 표는 원래 넓어(2066px) **2150px 이상**에서만 남는 폭이 생긴다.
토양은 1700px부터였다. 4K나 큰 모니터를 쓰는 곳에서만 보이던 증상이다.

## 검증

- E2E: 2200px에서 전체 보기 토글 → 농장주소 외에는 폭이 안 바뀐다
- E2E: 좁은 화면(1800px)에서는 예전처럼 250px를 지킨다 — **설계 의도 회귀 방지**
- E2E: 두 줄 표시(`white-space: normal`)가 유지된다
- 실기: Electron에서 눈으로

## 종료 조건

사용자가 두 안 중 '농장주소'를 선택 (2026-08-27).
