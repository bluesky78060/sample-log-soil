이런 일을 할 수 있어요

토양 시료 접수 현장에 필요한 기능을 모았습니다.

📝

시료 접수·관리

논·밭·과수·시설 토양 시료를 접수하고 연도별로 관리합니다.

🌱

흙토람 연동

흙토람 검정결과를 엑셀로 가져오고, 흙토람·공익직불제 서식으로 내보냅니다.

📍

본필지·하위필지

한 접수에 여러 필지와 작물을 묶어 자동으로 번호를 매깁니다.

☁️

오프라인 우선 저장

인터넷이 끊겨도 안전하게 저장하고, 연결되면 클라우드와 동기화합니다.

🏷️

라벨 인쇄·통계

시료 라벨을 인쇄하고, 경지구분·기간별 접수 통계를 한눈에 봅니다.

🔍

주소 자동완성 데스크톱

리 이름만 입력해도 우리 지역 필지 주소를 빠르게 찾아줍니다.

화면 미리보기

실제 프로그램 화면입니다.

메인 화면

한눈에 보는 통계

첫 화면에서 올해 접수 건수·완료율·이번 달 접수를 바로 확인합니다. 토양 카드를 누르면 접수 화면으로 이동합니다.

시료 접수

필지·작물을 한 번에

기본 정보와 필지 정보를 나란히 입력합니다. 한 필지에 여러 작물, 한 접수에 여러 필지를 추가해도 접수번호가 자동으로 정리됩니다.

접수 목록

찾고, 거르고, 내보내기

연도·경지구분별로 목록을 보고, 검색·필터로 원하는 시료만 추립니다. 엑셀로 내보내 보고서에 바로 활용하세요.

라벨 인쇄

시료 라벨 출력

접수한 시료의 라벨을 보기 좋게 인쇄합니다. 현장에서 시료를 빠르고 정확하게 구분할 수 있습니다.

웹 vs 데스크톱, 무엇을 쓸까요?

접수·통계·라벨·흙토람 연동 등 핵심 기능은 두 버전이 같습니다. 사용 환경에 맞게 고르세요.

🌐 웹 버전

설치 없이 브라우저에서 바로. 간단 조회·외부 공유·설치가 어려운 PC에 적합합니다.

  • 시료 접수·수정·삭제
  • 통계 패널 · 라벨 인쇄
  • 흙토람 검정결과 가져오기 / 내보내기
  • 오프라인 저장 · 클라우드 동기화
  • 주소 자동완성 — 주소 직접 입력
  • 파일 자동저장 — 클라우드 동기화로 대체
  • 자동 업데이트 — 새로고침하면 항상 최신
현장 권장

🖥️ 데스크톱 버전

Windows 설치형. 매일 접수를 입력하는 담당자께 권장합니다.

  • 웹 버전의 모든 기능 포함
  • 주소 자동완성 — 리 이름만으로 빠른 검색
  • 파일 자동저장 — 입력 즉시 로컬에 백업
  • 자동 업데이트 — 새 버전 자동 설치
  • 지번 좌표 검증

두 버전은 같은 데이터를 사용해 서로 호환됩니다. 웹은 파일 자동저장이 없으므로, 중요한 데이터는 클라우드 동기화를 켜두시길 권장합니다.
