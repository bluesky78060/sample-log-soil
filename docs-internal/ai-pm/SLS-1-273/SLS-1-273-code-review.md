## 리뷰어가 확인해 준 것

- `rawVal`은 `getVal(row, field)`만 부르는 **순수 클로저**다. `buildRecord`는 호출만 하고
  함수나 행 상태를 바꾸지 않는다 — 오염·잔여 상태 없음
- `skipRowCheck` 설정자는 저장소 전체에서 **compost 한 곳뿐**이라 시그니처 변경이
  다른 소비자를 깨지 않는다
- `record` 대신 `raw`를 보는 것이 정확하다 — 기본값과 공통 대표자 보정 때문에
  `record` 검사로는 **실제 빈 행을 판별할 수 없다**
- 전건 탈락 시 `_parsedLogs.length === 0`에서 가져오기가 중단되고 모달이 유지된다.
  콜백·저장·모달 닫기가 실행되지 않는다
