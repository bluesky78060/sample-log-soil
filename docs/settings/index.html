인증 파일이란?
Firebase 접근을 위한 인증 파일(firebase-auth.json)을 등록해야 클라우드 동기화가 활성화됩니다. 인증 파일은 관리자에게 받으세요.

삭제 대상 연도는 자동으로 선택되어 있습니다. 보관 기간(3년) 내 연도는 보호되어 선택할 수 없습니다. 삭제한 자료는 복구할 수 없습니다.
