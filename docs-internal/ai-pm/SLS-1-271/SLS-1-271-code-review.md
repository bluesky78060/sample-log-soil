## MAJOR-1 — 1·2번 단언이 공허했다 (수정 완료)

> `#excelImportModal`은 페이지 초기 상태부터 `.hidden`이다. `setInputFiles()` 직후
> `toBeHidden()`을 실행하면 `FileReader.onload`와 XLSX 파싱이 시작되기도 **전에**
> 통과할 수 있다. 파일 처리가 망가져도 테스트가 통과한다.

정확한 지적이다. **이 티켓의 존재 이유가 "거절해야 할 입력을 실제로 거절하는가"인데,
거절 여부를 보지도 않고 통과할 수 있었다.**

→ `expectRejected()` 헬퍼를 만들어 **처리 완료 신호(오류 toast)를 먼저 기다린 뒤**
   모달 상태를 확인하도록 고쳤다. toast의 *존재*만 신호로 쓰고 문구에는 기대지 않는다.

**변이 (g)로 확인**: `jsonData.length < 2` 분기에서 모달을 잘못 열게 만들자
1번 테스트가 **실패**했다. 수정 전이라면 통과했을 변이다.
