설명서 섹션 순서 조정 (접수 목록 → 흙토람)
★ 최신 수정

v1.0.3 2026-05-09
사용설명서 토양 전용 화면 기준으로 갱신
신규
  • 메인 화면 + 통계 패널 스크린샷 — 신규 화면을 반영한 메인 화면 캡처와 통계 패널 4개 지표(올해 접수/이번 달/완료율/미완료) 설명 추가.
  • 토양 시료 접수 섹션 갱신 — 본필지/하위필지 구조, 접수번호 그룹핑(503, 503-1) 동작 방식 명시.
  • "3. 흙토람 결과 가져오기" 신규 섹션 — 엑셀 업로드/매핑/미리보기 단계별 안내, 자동 매핑 추정, 4가지 충돌 정책, 미매칭 CSV 다운로드 등 핵심 기능 문서화.
  • 다른 시료 타입 언급 제거 — 토양 전용 프로젝트 컨텍스트에 맞게 5종 시료 비교표·feature 카드를 토양/흙토람/라벨 인쇄 3개로 정리.
  • 섹션 번호 재구성 — 흙토람 섹션 추가에 따라 3~9 번호 +1 증가.
v1.0.2 2026-05-09
메인 통계 패널 CSP 차단 핫픽스
수정
  • Electron 앱에서 통계 패널 동작 안 되던 문제 수정 — Electron 메인 프로세스 CSP가 인라인 <script>를 차단하여 통계 값이 표시되지 않던 문제. 인라인 스크립트를 별도 ES 모듈(main-stats.js)로 분리하여 CSP 정책 준수.
  • 0건 placeholder 정상 표시 — 토양 시료가 등록되지 않은 신규 환경에서 "아직 등록된 토양 시료가 없습니다" 안내 메시지 정상 노출.
v1.0.1 2026-05-09
메인 페이지 통계 패널 + 빌드 안정화
신규 수정
  • 메인 페이지 토양 통계 패널 추가 — 올해 접수, 이번 달 접수, 완료율 프로그레스 바, 미완료 건수를 한눈에. localStorage 기반 즉시 표시, 다크모드/모바일 대응.
  • 미완료 카운트에서 하위필지 제외 — 503-1, F503-2 등은 카운트하지 않고 본필지(503, F503)만 집계. 토양 페이지 그룹핑 로직과 일관.
  • 흙토람을 토양 하위 기능으로 통합 — 메인 페이지에서 흙토람 카드 제거, 토양 페이지 툴바의 흙토람 버튼으로 진입 일원화.
  • Firebase 설정 가이드 페이지 빌드 누락 수정 — manual/firebase-setup.html, images/, screenshots/가 docs/에 정상 포함되도록 vite 플러그인 추가.
  • GitHub Actions 안정화 — Release 생성 권한(contents: write) + Node 24 강제(FORCE_JAVASCRIPT_ACTIONS_TO_NODE24) 추가.
