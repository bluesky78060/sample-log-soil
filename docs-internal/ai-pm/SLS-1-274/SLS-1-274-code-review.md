## MAJOR-1 — 세 번째 항목이 변경되지 않은 기능을 홍보했다 (삭제)

초안:

> 목록에서 용도·경지구분을 고를 때 표시가 **더 정확해졌습니다.**

**사실이 아니다.** SLS-1-197은 **동작 보존 리팩터**다 —
`getFilterKeys()`가 토양 전용 필터를 그대로 유지하고, `purposeFilter`·`landClass1Tab`
배지도 그대로이며, 검색 버튼 표시도 동일하다. **사용자 체감 변화가 0이다.**

→ 항목을 통째로 삭제했다. 리팩터·테스트 커밋은 릴리스 노트에 넣지 않는다.

## MINOR-1 — "내용이 없는 줄"이 실제 조건보다 넓다

실제 조건은 "모든 셀이 빈 행"이 아니라 **"농장명·대표자·시료종류 세 필드가 모두 빈 행"**이다.
비고·주소만 있는 행도 건너뛴다.

→ 제목을 **"농장명·대표자·시료종류가 모두 비어 있는 줄은 등록하지 않습니다"**로 바꾸고,
   "셋 중 하나라도 적혀 있으면 그대로 등록" → **"세 항목 중 하나라도 입력되어 있으면
   해당 줄은 등록됩니다"**로 정정했다(접수번호·날짜 등은 자동 보완되므로 "그대로"는 부정확).
