# SLS-1-279 Discovery — 전체 보기에서 열이 전부 줄어들던 것

> 정본. `docs/00-discovery/`의 사본은 훅 통과용 일회용이다.

작성: 2026-08-27 · 상태: **방향 확정** (사용자 실기 확인 + 선택)

## 어디서 나왔나

SLS-1-278을 넣은 뒤 사용자가 **실기에서 직접 확인**하고 두 가지를 알렸다.

> "전체보기에서 컬럼의 크기가 바뀌면서 보이게 되고 발송일자와 관리의 라인 구분선이 약해져"

스크린샷도 함께 받았다(농가의뢰 911건, 전체 보기 상태, 가로로 민 화면).

## ① 전체 보기를 켜면 모든 열이 줄어든다

`.data-table`은 `width: 100%`다(`style.css:3612`). 표가 화면보다 **좁으면** 남는 폭을
모든 열이 나눠 갖는다. 그 상태에서 전체 보기로 열 둘(경지구분·우편번호)이 끼어들면
**나머지가 전부 그만큼 양보한다.**

실측(120건, 전체 보기 토글 전후):

| 화면 폭 | 표가 넘치나 | 폭이 바뀐 열 |
| --- | --- | --- |
| 1280 · 1440 · 1600 | 넘침 → 넘침 | **0개** (남는 폭이 없어 분배할 것이 없다) |
| 1700 | 딱 맞음 → 넘침 | 2개 |
| **1800** | 딱 맞음 → 넘침 | **14개** (완료 −21, 접수일자 −10, 필지 주소 −32 …) |
| 1920 · 2200 | 안 넘침 | 14개 |

**1700px 언저리부터** 눈에 띈다. 넓은 화면을 쓰는 곳에서 전체 보기를 누르면 표
전체가 한 번 움찔한다.

### 사용자가 고른 해법 — 주소 열이 남는 폭을 흡수

세 안을 그림과 함께 제시했고 사용자가 **첫째**를 골랐다.

| 안 | 결과 | 선택 |
| --- | --- | --- |
| 주소 열이 남는 폭을 흡수 | 다른 열은 내용 폭 고정. 전체 보기를 켜도 주소만 줄어든다 | ✅ |
| 표를 내용 폭 그대로 | 어떤 열도 안 늘어나지만 넓은 화면에서 오른쪽에 빈 공간 | |
| 지금 배분 유지 + 구분선만 | 변경 범위 최소, 열 움찔은 남음 | |

**처방을 실제로 시험했다** (1800px):

| | 폭이 바뀐 열 |
| --- | --- |
| 지금 | **14개** |
| `.col-lot-address { width: 100% }` 적용 후 | **1개** (필지 주소 336 → 208) |

## ② 관리 열 왼쪽 구분선이 혼자 약하다

| | 일반 열 경계 | 관리 열 왼쪽 |
| --- | --- | --- |
| 라이트 | `#d0d7de` | **`#e2d9c8`** (연한 베이지) |
| 다크 | `#57534E` | **`#44403c`** (더 어두움) |
| 퇴비 라이트 | `#d0d7de` | **`#bbf7d0`** (연한 초록) |

관리 열은 **오른쪽 고정**이라 스크롤되는 내용 위에 떠 있다. 그 경계는 오히려 다른
경계보다 **분명해야** 하는데 지금은 정반대로 가장 약하다.

## 범위

| # | 대상 | 처방 |
| --- | --- | --- |
| 1 | 토양 목록 | 필지 주소 열이 남는 폭을 흡수 |
| 2 | 퇴비 목록 | 같은 구조 — 농장주소 열이 흡수 |
| 3 | 두 목록의 관리 열 | 왼쪽 구분선을 다른 열과 같은 색으로 |

## 제약

- 토양의 `필지 주소`는 **`td`에만** `col-lot-address` 클래스가 있다
  (`soil-script.js:4041`). 머리글에는 없으므로 HTML에 추가해야 한다.
- 1024px 이하에서는 관리 열 고정이 풀리고 `border-left: none`이 된다
  (SLS-1-260). 그 규칙을 깨뜨리지 않아야 한다.
- 다크 모드 규칙이 따로 있다 — 함께 고쳐야 한다.

## 리스크

| 리스크 | 완화 |
| --- | --- |
| 흡수 열이 너무 좁아져 주소가 잘린다 | `white-space: nowrap`이라 콘텐츠 최소 폭 아래로는 안 줄어든다. 실측 208px |
| 평소 화면에서 주소 열이 지금보다 넓어진다 | **사용자가 그림으로 보고 고른 결과다** |
| 퇴비의 흡수 열 선택이 어색하다 | 농장주소가 가장 길고 가변적이다 — E2E로 확인 |

## 검증

- E2E: 넓은 화면(1800px)에서 전체 보기 토글 → 흡수 열 외에는 폭이 안 바뀐다 (토양·퇴비)
- E2E: 관리 열 왼쪽 경계 색이 일반 열 경계와 같다 (라이트·다크)
- 실기: Electron에서 눈으로

## 종료 조건

사용자가 세 안 중 "주소 열이 남는 폭을 흡수"를 선택 (2026-08-27).
