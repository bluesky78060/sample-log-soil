## MINOR

**m-1. `mtimeMs` 비교는 위음성이 가능하다.** 파일시스템 해상도가 낮거나 두 write가
같은 밀리초에 일어나면 재작성을 놓친다.
→ `statSync(target, { bigint: true }).mtimeNs`로 **나노초** 비교로 바꿨다. 내용 비교도 유지.

**m-2. CLI 실패 계약이 부분만 검증된다.** 버전 누락 경로의 stderr를 일부만 보고,
`.version-entry` 없음 경로는 in-process로만 본다.
→ 16번에 stderr **3줄 계약**(버전·조치 안내·최신 버전)과 "실패 시 산출물 미생성"을 추가.
   구조 변경 감지 테스트에는 `result.error`·`result.detail` **반환 계약**을 단언으로 고정했다.
