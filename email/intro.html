토양 시료 접수 대장

시료 접수부터 흙토람 검정결과 연동, 라벨 인쇄, 통계까지
토양 분석 업무를 한 프로그램에서 처리하세요.

토양 시료 접수 대장은 토양 시료의 접수·관리·통계를 한 곳에서 처리하는 프로그램입니다. 인터넷이 끊겨도 안전하게 저장되고, 흙토람 검정결과와 공익직불제 서식까지 연동됩니다. Windows에 설치하거나 설치 없이 웹에서 바로 사용할 수 있습니다.

✅  시료 접수·관리 — 논·밭·과수·시설 토양을 연도별로 관리
✅  흙토람 연동 — 검정결과 가져오기 / 공익직불제 서식 내보내기
✅  본필지·하위필지 — 한 접수에 여러 필지·작물 자동 번호 부여
✅  라벨 인쇄·통계 — 시료 라벨 출력, 경지구분·기간별 통계
✅  오프라인 우선 저장 — 끊겨도 저장, 연결되면 클라우드 동기화
⬇️ Windows 설치 파일 받기

설치 없이 바로 쓰기: 웹에서 사용하기
자세한 소개: 소개 페이지  ·  변경 내역
설치 파일은 항상 최신 버전이며, 설치 후 자동 업데이트됩니다.
